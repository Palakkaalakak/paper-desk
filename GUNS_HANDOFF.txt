1. `guns_data.py`: read-only scanner/news/history helpers.
2. `guns.js`: pure strategy/math library, usable both in browser and Node tests.
3. `guns-execution.js`: pure-ish paper execution controller accepting a bridge to the existing account engine.
4. `guns-ui.js`: browser UI/controller, incomplete.
5. `guns.css`: planned, not created.

Browser modules use UMD-style globals / CommonJS:
```javascript

  if(typeof module==='object'&&module.exports)
    module.exports=f();
  else root.Guns=f();

```

The main inline app is inside an IIFE. New modules cannot directly access its `S`, `Q`, `acct()`, etc. They need a bridge instantiated near the end of the inline script.

## Risk and execution design
- Budget from current `acct().netLiq`.
- Require fresh quotes for all held positions before opening/resizing a GUNS entry.
- Size using worst allowed entry (`plan.limit`) versus stop, plus estimated round-trip commissions.
- Binary search whole-share count that fits risk and buying power.
- Recalculate pending quantity and budget before trigger/fill.
- One position owner per symbol to avoid mixing independent strategies into a bracket.
- At most two pending/open GUNS trades.
- Available-size entry fill; cancel unfilled remainder rather than leave unprotected residual demand.
- Stops/targets protected via one mutually exclusive position-management lifecycle.
- Partial exit limited by actual held quantity and displayed bid size.
- Stop trigger remains latched across later ticks.
- Optional stop to actual entry at +1R.
- Auto-exit near session end.
- No fabricated historical fills, quote prices, candles or depth.

- D1/managed storage was proposed, not provisioned.

Analysis:
- Only closed minute bars (`t+60000<=now`) generate signals.
- Aggregates closed five-minute bars.
- Session found by NY date against broker liquid sessions.
- Premarket begins session start minus 19,800,000 ms (5.5 hours; assumes normal US 09:30 open).
- Uses previous completed daily close for gap.
- Checks:
  - Known tick >0 and ≤.01.
  - `stockType==='COMMON'` or user `notes.common`.
  - $1.50 minimum.
  - 5% gap.
  - Configured premarket volume.
  - Manual `notes.catalyst`.
  - Manual `notes.room`.
  - Chart stream updated less than 90 seconds ago.
  - Session known.
  - Tight two-sided spread.
  - Pattern-specific rules.
  - Above all four moving averages.
  - Entry window.
  - Valid stop/target.
  - Resistance room.
  - No chasing above limit.
- S1–S3 can arm beginning 2 minutes before open.
- S1–S3 expire open+5min.
- S4 expires open+1hour.
- S5 expires open+2min.
- S5 app guardrail: first candle range ≤2×premarket ATR, explicitly labeled as an app guardrail.
- S1/S2 stop choices:
  - ATR.
  - Price ladder: .15 below $20; .25 below $30; .40 below $50; .50 otherwise.
  - User fixed distance.
- S3–S5 stop below trigger candle low.
- Entry trigger + tick.
- Limit entry + .03 if entry<$20, otherwise +.05.
- Target initially based on planned entry; actual bracket later recalculates from fill.

### Dynamic sizing — critical
```javascript
function size(equity,pct,entry,stop,bp,fees){
  const budget=equity*pct/100, d=entry-stop;
  // validate finite positive inputs
  // binary search whole shares
  // n*d + fees(n) <= budget
  // n*entry + fees(n) <= bp
  return {
    equity, budget, qty,
    risk:qty*d+fee,
    fees:fee,
    unused:budget-qty*d-fee
  };
}
```
- Budget is not rounded to a static preset.
- Fees callback includes both buy and sell commissions.
- Tests still need to be written.

### Exit decision
```javascript
function exit(b,q,now){
  if(b.forceExit || b.stopTriggered || q.bid<=b.stop)
    return {reason:b.forceExit?'MANUAL FLATTEN':'STOP',stop:b.stop};

  if(now>=b.sessionEnd-60000)
    return {reason:'SESSION CLOSE',stop:b.stop};

  if(q.bid>=b.target)
    return {reason:'TARGET',stop:b.stop};

  return {
    reason:null,
    stop:b.breakeven && q.bid>=b.entry+b.initialR
      ? Math.max(b.stop,b.entry)
      : b.stop
  };
}
```

### `guard(order)`
For non-GUNS orders:
- Checks same-symbol active GUNS exposure.
- Rejects BUY increase or SELL larger than held position.
- Intended to be called at start of main `tryFill` before combos execute.
- This is important to avoid partially executing a combo before discovering bracket conflict.

### `fill(order)`
Returns:
- `null` if not a GUNS order.
- Boolean handled/changed otherwise.

Entry logic:
1. Expire if `now>=plan.expiresAt`.
